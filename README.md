# MontanaOpenAITV · antecedente de YaVale

El desarrollo activo esta en [M264921/yavale](https://github.com/M264921/yavale).
Este repositorio conserva el historial inicial y sus plantillas VPN; no contiene
una app iOS terminada ni un servidor Stremio propio.

El formulario antiguo referenciaba dos JavaScript ausentes. Su reemplazo mantenido
es [Abrir enlace](https://m264921.github.io/yavale/open-stream.html), con validacion
del hash y motor configurable. `index.html` conduce a esa unica implementacion.
Para el catalogo usa [MontanaTV / YaVale](https://m264921.github.io/yavale/).

Las configuraciones VPN son antecedentes: contrasta red y claves vigentes antes
de usarlas. No se ha activado ninguna VPN durante esta consolidacion.
